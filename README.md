# 郭磊私董专家团（guolei-peer-board）

> 企业主带案题入席的私董会圆桌：私董官主持，六路幕僚只提问不给建议、照见盲区，重构真问题后以行动承诺＋监督人收口。跨会话累积案主档案（落盘本地 `~/咨询档案/`）。

一套提示词资产，两种形态、多个平台可用：

| 形态 | 位置 | 适用平台 |
|------|------|----------|
| **对话式 skill 七件套 + 案前收纳** | `skills/` | Claude Code、Codex 及任何兼容 agentskills.io 规范（SKILL.md + frontmatter）的 Agent |
| **Team 型专家包** | `.codebuddy-plugin/` + `agents/` + `rules/` | WorkBuddy（CodeBuddy）专家市场 |

纯对话型，不依赖任何专有工具调用；单技能可独立运行，整团可开完整私董会。

## 私董八 Phase

案前打磨（含「你要答案就别来」筛题红线）→ 案题陈述（倾听四层：事实/感受/意图/心智模式）→ 幕僚之问两轮（只提问不给建议；提问四标准）→ 真问题重构（公式：我＋我如何＋资源限制＋具体行动＋价值）→ 隔墙有耳（案主静默、幕僚对质）→ 幕僚反馈三段式（我的感受/一句话真问题/个人经验；建议必须「如果我是你」开头）→ 承诺收口（监督人只能一位）→ 送一朵小红花。续会首动作＝对账上次承诺。

护栏：案主开放度上限三分、不苛责不逼问；不纠正限制性信念（很多人的限制性信念就是他暂时成功的原因）；保密承诺（一切只存本地）。

## 使用示例

- 帮我开一场私董会，盘盘我生意上最大的难题
- 我说不清问题到底出在哪，帮我重新框定真问题
- 我的计划大家都说好，找人来挑挑刺（直调黑帽子）
- 让商业模式幕僚看看我这个生意（点名幕僚）
